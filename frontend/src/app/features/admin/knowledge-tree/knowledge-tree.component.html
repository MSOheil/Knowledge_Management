راهنمای ساختار درخت دانش:

درخت دانش به عنوان نقشه جامع فکری شهرداری اصفهان عمل می‌کند. تجارب، درس‌آموخته‌ها، پروژه‌های تحقیقاتی و کتب به این گره‌ها متصل می‌شوند. برای افزودن زیرشاخه، ابتدا شاخه مورد نظر را انتخاب نموده و سپس روی «افزودن زیرشاخه» کلیک فرمایید.
